Setup Required

To use Gmail import, you need to configure Google OAuth credentials:

  1. Go to Google Cloud Console
  2. Create a new project (or select existing)
  3. Enable the Gmail API
  4. Create OAuth 2.0 credentials (Web application)
  5. Add http://localhost:8000/api/gmail/callback as an authorized redirect URI
  6. Download the credentials JSON and save as credentials.json in the project root
